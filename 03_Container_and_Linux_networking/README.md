# Container & Linux Networking

## Lecture Sequence

- [Introduction To Linux Networking For Containers](./01_Introduction_to_Linux_Networking_for_Containers/README.md)
- [Iptables And Basics Of The Linux Kernel Firewall](./02_Iptables_and_basics_of_the_Linux_kernel_firewall/README.md)

- [Common Traps Of Container Networking](./04_Common_traps_of_container_networking/README.md)

These four modules are designed to run as one connected block of roughly 3.5 hours:

- Module 1 explains the Linux primitives Docker builds on
- Module 2 explains how packet filtering, NAT, and forwarding actually work
- Module 3 explains Docker network drivers, service discovery, and multi-host networking
- Module 4 turns that model into concrete failure patterns and defensive best practices
