# Hardening & Defense-in-Depth

## Lecture Sequence


- [Container Hardening Strategies](./02_Container_hardening_strategies/README.md)
- [Managing Secrets In Containerized Environments](./03_Managing_Secrets_in_Containerized_Environments/README.md)
- [Container Monitoring And Observability](./04_Container_Monitoring_and_Observability/README.md)

These four modules are designed to run as one connected block of roughly 4 hours:

- Module 1 shows how ordinary web application flaws still become the initial access path in containerized systems
- Module 2 focuses on reducing the blast radius with runtime and platform hardening
- Module 3 focuses on secrets as one of the first things attackers try to steal after compromise
- Module 4 focuses on the telemetry, detection, and operational visibility needed to notice attacks and respond fast
